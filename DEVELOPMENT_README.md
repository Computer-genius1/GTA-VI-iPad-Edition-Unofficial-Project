# GTA VI iPad Edition — Unofficial Prototype

An open-source, original **South-Florida-inspired open-world prototype** for Apple Silicon iPads (M3 and newer). This project is not an official Rockstar Games product and does not include GTA VI assets, source code, or map files.

## First development drop
- Procedural coastal city prototype: grid streets, wide boulevard, beach, ocean, palm-lined road, downtown skyline and varied building silhouettes.
- Basic third-person character movement (WASD + mouse for desktop testing).
- Godot 4 project scaffold; intended iPad/mobile optimization work is underway.
- Original generated map geometry; no copied proprietary game content.

## Run
Open this folder in **Godot 4.x** and run `scenes/main.tscn`. Desktop controls: **W/A/S/D** to move, mouse to look, Escape to release the cursor.

## Planned
Touch controls and iPad device gate; road traffic and pedestrians; original vehicle models and driving; expanded districts and map streaming; improved materials, windows, lighting, and environmental details.
