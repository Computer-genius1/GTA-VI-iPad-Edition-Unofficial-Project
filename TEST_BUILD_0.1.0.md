# Test Build 0.1.0

## Added
- Initial procedural Leonida-inspired coastal map blockout with beach, promenade, ocean, palm-lined waterfront, city blocks, downtown tower and boulevard.
- Third-person player controller with smoothing, sprint and jump.
- Mouse and touch-drag camera look.
- Prototype vehicle with acceleration, reverse, steering, braking and enter/exit.
- Vehicle chase camera.
- HUD, keyboard hints and virtual touch controls.
- Landscape setup and mobile renderer setting.
- Project documentation and legal disclaimer.

- Mobile performance and touch behavior
- iOS export or installation on iPad
